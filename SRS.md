1.1 Purpose

The purpose of the Quiz Game is to provide users with a simple and interactive application for answering quiz questions. The system allows users to select answers, receive immediate feedback, calculate their score, and view the final result after completing the quiz 1.2 Scope

The Quiz Game allows users to start a quiz and answer a series of multiple-choice questions. Each question contains multiple answer options, from which the user can select one answer. The system checks the selected answer and updates the score accordingly. After all questions are completed, the system displays the user's final score.3. Functional Requirements

### 3.1 Start Quiz

The system shall allow the user to start the quiz.

### 3.2 Display Questions

The system shall display one quiz question at a time.

### 3.3 Display Answer Options

The system shall display multiple answer options for each question.

### 3.4 Select Answer

The system shall allow the user to select one answer for each question.

### 3.5 Check Answer

The system shall check the selected answer against the correct answer.

### 3.6 Update Score

The system shall increase the user's score when the selected answer is correct.

### 3.7 Display Feedback

The system shall provide feedback based on the user's selected answer.

### 3.8 Display Next Question

The system shall display the next question after the current question is answered.

### 3.9 Display Final Result

The system shall display the user's final score after all questions have been answered.

### 3.10 Restart Quiz

The system shall allow the user to restart the quiz and play again.
4. Non-Functional Requirements

### 4.1 Usability

The application shall provide a simple, clear, and user-friendly interface.

### 4.2 Performance

The system shall respond quickly to user actions such as selecting an answer and moving to the next question.

4.3 Reliability

The system shall correctly check answers and calculate the user's score.

4.4 Availability

The application should be available whenever the user launches the Quiz Game.

4.5 Maintainability

The system should be easy to maintain and update, especially when adding new questions or modifying existing questions.

4. Interface Requirements

4.1 GUI (Graphical User Interface)

The system shall provide a simple and user-friendly graphical interface.

The system shall provide a start button to begin the quiz.

The system shall display questions and multiple-choice options.

The system shall provide buttons to select answers and move to the next question.

The system shall display the user's score after completing the quiz.


4.2 Input Interface

The user shall select an answer from the given multiple-choice options.

The user shall click the Start button to begin the quiz.

The user shall click the Next button to proceed to the next question.

The user shall provide valid inputs through the available buttons.


4.3 Output Interface

The system shall display quiz questions and answer options.

The system shall display the selected answer.

The system shall display the final score after the quiz.

The system shall display the quiz result/status to the user.


4.4 Hardware Interface

The system shall require a computer, laptop, tablet, or smartphone.

The device shall have a display screen for showing the quiz interface.

The device shall have an input mechanism such as a keyboard, mouse, touchscreen, or touchpad.


4.5 Software Interface

The quiz game shall run on a supported operating system.

The system shall require a suitable web browser if implemented as a web application.

The system shall use a database or local storage if required to store quiz questions and scores.
