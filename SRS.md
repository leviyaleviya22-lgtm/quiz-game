SOFTWARE REQUIREMENTS SPECIFICATION (SRS)
Quiz Game

1. Introduction

1.1 Purpose

The purpose of the Quiz Game is to provide users with a simple and interactive application for answering
multiple-choice questions. The system allows users to start a quiz, select answers, move through questions,
and view their final score after completing the quiz.

1.2 Scope

The Quiz Game provides a user-friendly interface through which users can participate in a quiz. The system
displays questions with multiple-choice answers, accepts the user's selections, processes the answers, and
displays the final result. The application can be implemented as a web, desktop, or mobile application
depending on the project requirements.

1.3 Objectives

• To provide an easy-to-use quiz application.
• To display questions and multiple-choice options clearly.
• To allow users to select and submit answers.
• To calculate and display the user's score.
• To provide a simple and interactive quiz experience.

2. Functional Requirements

• The system shall allow the user to start the quiz.
• The system shall display quiz questions with multiple-choice options.
• The system shall allow the user to select an answer.
• The system shall accept and process the selected answer.
• The system shall allow the user to move to the next question.
• The system shall calculate the user's score based on the answers.
• The system shall display the final score after completing the quiz.
• The system shall display the quiz result/status to the user.
• The system shall store quiz questions and scores using local storage or a database if required.

3. Non-Functional Requirements

• Usability: The system shall provide a simple, clear, and user-friendly interface.
• Performance: The system shall respond to user actions and display questions without unnecessary delay.

• Reliability: The system shall correctly process selected answers and calculate the score.

• Compatibility: The application shall be usable on a supported computer, laptop, tablet, or smartphone.• Maintainability: The system should be easy to update with new questions and quiz content.

• Security: User and quiz data, if stored, should be protected from unauthorized access.

• Availability: The quiz application should be available whenever the user launches the application.

4. Interface Requirements

4.1 GUI (Graphical User Interface)

• The system shall provide a simple and user-friendly graphical interface.
• The system shall provide a Start button to begin the quiz.
• The system shall display questions and multiple-choice options.
• The system shall provide buttons to select answers and move to the next question.
• The system shall display the user's score after completing the quiz.

4.2 Input Interface

• The user shall select an answer from the given multiple-choice options.
• The user shall click the Start button to begin the quiz.
• The user shall click the Next button to proceed to the next question.
• The user shall provide valid inputs through the available buttons.

4.3 Output Interface

• The system shall display quiz questions and answer options.
• The system shall display the selected answer.
• The system shall display the final score after the quiz.
• The system shall display the quiz result/status to the user.

4.4 Hardware Interface

• The system shall require a computer, laptop, tablet, or smartphone.
• The device shall have a display screen for showing the quiz interface.
• The device shall have an input mechanism such as a keyboard, mouse, touchscreen, or touchpad.

4.5 Software Interface

• The quiz game shall run on a supported operating system.
• The system shall require a suitable web browser if implemented as a web application.
• The system shall use a database or local storage if required to store quiz questions and scores.
